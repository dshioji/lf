# LF Fork Key Shortcuts

## Navigation (Normal & Visual Mode)

| Key | Action |
|-----|--------|
| `k` / `↑` / `MouseWheelUp` | Move up |
| `j` / `↓` / `MouseWheelDown` | Move down |
| `h` / `←` | Go to parent directory |
| `l` / `→` | Open file/directory |
| `gg` / `Home` | Go to top |
| `G` / `End` | Go to bottom |
| `H` | Go to high (top of visible) |
| `M` | Go to middle |
| `L` | Go to low (bottom of visible) |
| `[` | Jump to previous directory |
| `]` | Jump to next directory |
| `gh` | Go to home directory |

## Scrolling (File List)

| Key | Action |
|-----|--------|
| `Ctrl+u` | Half page up |
| `Ctrl+d` | Half page down |
| `Ctrl+b` / `PgUp` | Page up |
| `Ctrl+f` / `PgDn` | Page down |
| `Ctrl+y` / `Ctrl+MouseWheelUp` | Scroll up (keep cursor) |
| `Ctrl+e` / `Ctrl+MouseWheelDown` | Scroll down (keep cursor) |

## Preview Scrolling (Fork Feature)

| Key | Action |
|-----|--------|
| `J` | Scroll preview down 1 line |
| `K` | Scroll preview up 1 line |
| `Shift+↓` | Scroll preview down 1 line |
| `Shift+↑` | Scroll preview up 1 line |
| `Shift+PgDn` | Scroll preview down 1 page |
| `Shift+PgUp` | Scroll preview up 1 page |
| `Shift+MouseWheelDown` | Scroll preview down 3 lines |
| `Shift+MouseWheelUp` | Scroll preview up 3 lines |
| MouseWheel over preview | Scroll preview 3 lines |

## Selection

| Key | Action |
|-----|--------|
| `Space` | Toggle selection and move down |
| `v` | Invert selection |
| `u` | Unselect all |
| `t` | Toggle tag |

## Visual Mode

| Key | Action |
|-----|--------|
| `V` | Enter visual mode |
| `V` (in visual) | Accept visual selection |
| `Esc` (in visual) | Discard visual selection |
| `o` (in visual) | Change visual anchor |

## File Operations

| Key | Action |
|-----|--------|
| `y` | Copy (yank) |
| `d` | Cut |
| `p` | Paste |
| `c` | Clear clipboard |
| `r` | Rename |

## Marks

| Key | Action |
|-----|--------|
| `m` | Save mark |
| `'` | Load mark |
| `"` | Remove mark |

## Search & Find

| Key | Action |
|-----|--------|
| `/` | Search forward |
| `?` | Search backward |
| `n` | Next search match |
| `N` | Previous search match |
| `f` | Find (single char) |
| `F` | Find backward |
| `;` | Next find match |
| `,` | Previous find match |

## Shell Commands

| Key | Action |
|-----|--------|
| `:` | Command prompt |
| `$` | Shell command |
| `%` | Shell pipe |
| `!` | Shell wait |
| `&` | Shell async |

## Display Options (z prefix)

| Key | Action |
|-----|--------|

| `zr` | Toggle reverse sort |
| `zn` | Show no info |
| `zs` | Show size info |
| `zt` | Show time info |
| `za` | Show size and time info |

## Command Line Mode

### Editing

| Key | Action |
|-----|--------|
| `←` / `Ctrl+b` | Move left |
| `→` / `Ctrl+f` | Move right |
| `Home` / `Ctrl+a` | Go to start |
| `End` / `Ctrl+e` | Go to end |
| `Delete` / `Ctrl+d` | Delete char |
| `Backspace` | Delete char back |

| `Ctrl+k` | Delete to end |
| `Ctrl+w` | Delete word back |

## Key Notation

| Notation | Meaning |
|----------|---------|
| `Ctrl+x` | Hold Ctrl and press x |
| `Alt+x` | Hold Alt and press x |
| `Shift+x` | Hold Shift and press x |
| `<m-x>` | Mouse button/wheel |
| `<c-x>` | Ctrl+x |
| `<a-x>` | Alt+x |
| `<s-x>` | Shift+x |
